## A 3.1.1 Array Creation and Access (Abhinav)

| Folder | Program | What it shows |
|---|---|---|
| `A311-ArrayCreationAndAccess/GoalKeeper` | `GoalKeeper.java` | Initializer lists, accessing and changing elements |
| `A311-ArrayCreationAndAccess/GoalKeeper2` | `GoalKeeper2.java` | Creating arrays with `new` and default values |
| `A311-ArrayCreationAndAccess/Partners` | `Partners.java` | String arrays, `null` elements, two references to one array |
| `A311-ArrayCreationAndAccess/DogArrays` | `DogArray.java`, `Dog.java` | Arrays of objects and array limitations |

Erroneous statements from the activity are commented out with a note explaining each error.

To run one, for example:

```
cd A311-ArrayCreationAndAccess/DogArrays
javac DogArray.java Dog.java
java DogArray
```
